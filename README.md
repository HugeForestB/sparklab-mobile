# Interactive projects

Six interactive projects by Nathan Bonfanti, including five science experiences and a pumpkin recipe decision tree. Each project has its own folder.

- [Grade 6 Science Lab](projects/grade-6-science-lab/index.html)
- [Unit 1 Air Conditioner Lab](projects/air-conditioner-lab/index.html)
- [From moving particles to a thermometer reading](projects/particles-and-temperature/index.html)
- [Unit 2 Phenomena: Energy and Waves Through a Wireless Speaker](projects/energy-and-waves/index.html)
- [Density Tower Lab](projects/density-tower/index.html)
- [The Pumpkin Table — Recipe Decision Tree](projects/pumpkin-decision-tree/index.html)

## Running the projects

Download a project folder and open its index.html in a modern browser, or serve this repository with static hosting. The root index.html remains the existing SparkLab application.

The particle-and-temperature model and Density Tower Lab include Google Apps Script integration. Their server-backed submission features require the original Apps Script deployment; uploading these HTML files alone does not supply that backend.
